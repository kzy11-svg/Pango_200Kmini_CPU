## 功能及统计范围

完整软件运行系统仍包含乱序双整数执行通道、乘除法和 Zbc、CSR/异常/中断、分支预测、两路组相联指令/数据缓存、存储控制、定时器、UART 和原有板级外设。AI/专用 CoreMark 加速没有新增。
为了与 pure_software 的面积统计口径对应，本工程 CPU_top 中未实例化被动 PMU/ILA 观察模块，因此也没有活动的 ILA/JTAG 调试链；相关 RTL/IP 文件保留供对照。完整调试版本的最终时序尚未验证通过，不能把本工程的通过报告用于证明完整调试版本通过。
这不是完整功能合规认证。中断、取指异常和 Zbc 日志来自使用相同核心/串行执行逻辑、较早分支存储实现的候选；本版另有完整短 CoreMark 和 100,000 周期分支预测等价测试。

## 跑分限制

此次验证是 3 次迭代的短测试，四项 CRC 与原版一致，CPU 测量区间与原版同为 374679 周期，未降低 CoreMark/MHz。
运行时间不足正式 CoreMark 要求的 10 秒；日志会显示对应错误提示，不能把它当作正式认证分数。UART 的微秒定时读数会量化，直接打印的 Iterations/Sec 是 960.614793；上表 960.822464 是使用 CPU 周期得到的估算。未进行本次上板测试，未包含生成好的烧录文件。

## 重新构建

可以在 PDS 2025.2 中打开现有 .pds。由于旧运行数据库已清理，历史运行结果可能显示缺失，请从源码重新运行；在该工程目录运行 PDS shell：

`pds_shell.exe -file rebuild_pds2025.tcl -work_dir . -project_name r2_rebuild25`

保持本包 RTL、mem、ipcore 和约束的相对路径。重建可能因布局布线差异产生不同余量，需要查看新生成的最终时序报告。
未使用降频、新增假路径或多周期例外来取得本版结果；原有 CPU 与计时器异步时钟组约束保留。
